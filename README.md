# Расписание Е-21

📅 **Открыть приложение:** https://cdn2041.github.io/raspisanie-BTEU-E-21/

## Как установить на телефон

**iPhone:** открой ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить».

**Android:** открой ссылку в Chrome → меню ⋮ → «Добавить на главный экран».

Неделя (над чертой / под чертой) переключается автоматически.
После первого открытия работает без интернета.
