Вход

Нужен ключ доступа GitHub от аккаунта, которому открыт репозиторий расписания. Ключ сохранится только на этом устройстве.

  1. Войдите на github.com со своего аккаунта.
  2. Откройте Settings → Developer settings → Personal access tokens → Tokens (classic).
  3. Нажмите Generate new token (classic), отметьте только public_repo, срок можно поставить «No expiration».
  4. Скопируйте ключ (начинается с ghp_) и вставьте сюда.
